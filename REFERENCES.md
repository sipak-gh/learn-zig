# References

This file lists the sources behind the facts in this course: the language rules, standard library
behavior, version history, design rationale, and outside standards each chapter relies on. Use it
to check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the Internet
Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or changes).
Links into the Zig source code point at the `0.17.0` release tag on Codeberg, where Zig is
developed. Program output shown in the chapters comes from running the course's own code and isn't
listed here.
